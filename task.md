# Задача

Сделать визуальные модели лабораторных стендов для занятий по электроприводу.
Стендов два:
 - стенд для исследований привода постоянного тока
 - стенд для исследований привода переменного тока

Модель должна быть приближенна к реальным стендам.

# Структура стендов
На каждом стенде присутствуют следующие элементы управления и контроля:
 - автоматические выключателя для подачи питания на стенды
 - панель с силовыми клеммами для сборки схемы. Студент должен проводами выполнить соединения. Например соединить клеммы сетевого напряжения"A", "B", "C" со входными клеммами преобрзователя "U", "V", "W"
 - преобразователи напряжения
 - панель с кнопками и крутилками для запуска/останова преобразователей
 - панель с приборами для контроля напряжений и токов
 - смуфтированные двигатели

В зависимости от конкретного стенда, каждый из этих узлов отличается. Например на стенде привода постоянного тока стоят AC/DC преобразователи, а на стенде для переменного тока - преобразователь частоты
