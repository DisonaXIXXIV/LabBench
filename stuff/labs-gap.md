# Выполнимость лабораторных работ методички на модели стенда

Оценка по «Лабораторный практикум по курсу Электрический привод» (МЭИ, 2017,
7 работ) для версии модели `2026.09.20 18:49` (коммит `681c829`).
Сценарии прогонялись скриптом через `window.app` (провода → питание →
`rt.tick`) — что именно проверялось, отмечено «проверено».

Грубо: качественно снять точки по стрелочным приборам можно примерно в трети
пунктов программ (ЛР2 п.4–6, ЛР4 п.2/7, ЛР5 п.1–4, ЛР6 п.1/4). Количественно
сойтись с расчётами методички (п.1 каждой работы — «рассчитать по паспортным
данным / параметрам схемы замещения и сравнить») не может ни одна работа:
параметры машин в модели другие. ЛР1, ЛР3, ЛР7 сейчас невыполнимы.

## Что показали прогоны

- **Якорь через резистор.** `in3.+ → KM1 → R1(6,3) → Я+`, `KM2` шунтирует R1.
  До замыкания KM2 двигатель «stop», I_я = 0, PV2 = 0 (нетлист не объединяет
  сети через резистор, а модель берёт напряжение якоря как разность
  потенциалов сетей клеммников). После KM2 — 240 В на Rя = 0,4 Ом → 600 А →
  МТЗ 70 А, оба расцепителя. Тот же механизм ломает резисторы в статоре АД
  (ЛР6 п.2–3) и нагрузку 1,7 Ом на выходе ТП (ЛР2 п.2).
- **ДТ ДПТ.** ОВ от Ввода 3, якорь на 8,6 Ом (и накоротко), вал крутит ПЧ
  1000 об/мин: I_я = 0, PV2 = 0 (должно быть E ≈ 120 В), тормозного момента
  нет, датчик момента показывает 0,5 Нм.
- **ТП-Д.** ОВ от В+/В−, якорь от Я+/Я−, U = 240 В, нагрузка ПЧ в режиме M
  5…25 Нм: n = 1984 − 2,9·M, I_я = 4,8…26,5 А, генераторный режим при −10 Нм
  (n = 2013, I_я = −3,9 А) — правильно, но PV2 = 240 В при любом токе
  (Rтп = 0), а жёсткость соответствует Rя = 0,4 Ом вместо 1,03.
- **Датчик момента при «жёсткой» скорости.** ПЧ в режиме ω (и ТП в режиме ω):
  вал следует за заданием, M показывает 0,0005·n — момент нагрузки не
  измеряется. Методичка допускает ФМ1/ФМ2 в режиме ω для ДТ.
- **ЛР4 п.2.** М3 от сети через KM1, ротор через 4,2+1,2 Ом, нагрузка М4
  (треугольник) от ПЧ в режиме M 11…55 Нм: s = 33 → 165 %, опрокидывание
  при ~33 Нм — качественно верно. Но KM2 замкнулся сам через «Время 1»
  (цепочка контакторов фиксированная, удержать Rд можно только не подключая
  контакты), PV2 = 0, ток ротора — грубая оценка.
- **ЛР5 п.2.** М4 от ПЧ 50…10 Гц, ФМ3 (ТП на две фазы М3): работает, но
  I_п = U_тп/(2·r1) при r1 = 0,5 Ом даёт 48 А при 48 В («перегрев»), реальный
  r1 = 1,28 Ом; момент нагрузки мал; s_ном М4 ≈ 1 % (реально 3,5 %).
- **ЛР5 п.3, ЛР6 п.1.** Генераторные участки, тормозной резистор R1 на
  Br+/Br−, авария «ПЕРЕНАПРЯЖЕНИЕ ЗПТ» без него — работают.
- **ТПН.** Рампа 5 с до байпаса, пусковой ток до 60 А — работает, время не
  регулируется (ЛР7 п.4 — 1 с).

## Список изменений (по приоритету)

### 1. Резисторы и нагрузки в силовых цепях (блокер для ЛР1, ЛР2 п.2–3, ЛР3, ЛР6 п.2–3)

Сейчас потенциал сети = потенциал первого источника, обмотка видит только
сети своих клеммников. Нужен решатель цепи по нетлисту: источник → провода →
резисторы (последовательно/параллельно, через контакты KM) → обмотка.
Минимум — для радиальных цепей постоянного тока (якорь ДПТ, ОВ) и
симметричных трёхфазных (резисторы в фазах статора): найти путь от источника
к обмотке, просуммировать R, считать ток по I = (U − E)/(Rя + Rд).
Тогда же: нагрузка на выходе ТП (резистор 1,7 Ом, ЛР2 п.2), ток ваттметра
PW по его клеммам (сейчас — сумма токов всех статоров и cos φ = 0,85
константой), показания PV1/PV2 через резисторы.

### 2. Динамическое торможение ДПТ (ЛР1 п.5–6, ЛР2 п.3)

Якорь без источника, замкнутый накоротко или на резистор при поданном
возбуждении: I_я = −kΦ·ω/(Rя + Rдт), M = kΦ·I_я, PV2 = E − I·Rя.
Определяется по нетлисту после п. 1.

### 3. Параметры машин и формулы по методичке (все работы, п.1 «рассчитать и сравнить»)

- М1: 1750 об/мин, 28 А, 240 В, Rя = 1,03 Ом, Lя = 11,6 мГн, Rв = 167 Ом,
  Iв.ном = 1,44 А, Uв = 240 В, J = 0,029 (сейчас 2000 / 25 / 0,4 / 153 / 220).
- М2: 2000 об/мин, 30 Нм длительно (максимум 90), J = 0,0101.
- М3: Т-образная схема замещения r1 = 1,28, x1 = 1,74, r2' = 1,28,
  x2' = 2,317, x0 = 16,1 Ом, kпр = 2,56, I0 = 12,3 А, 925 об/мин, 2p = 6,
  U2к = 210 В, J = 0,068. Момент и токи считать по формулам (4.4)–(4.7)
  методички (с r1, а не по Клоссу), добавочное сопротивление ротора
  приводить через kпр² — иначе ЛР4 п.1/5 не сойдутся.
- М4: 5,5 кВт, 965 об/мин, 13,5 А (звезда 400 В), Mк/Mном = 2,8,
  Mп/Mном = 1,9, Iп/Iном = 5,6, J = 0,049 (сейчас Mк = 60 Нм ≈ Mном).
- Звезда/треугольник М4: фазное напряжение 220/380 В → Mк ∝ U², ток.
- Суммарный J агрегата: ≈ 0,041 кг·м² на стороне ДПТ, ≈ 0,12 на стороне АД
  (сейчас 0,4) — переходные ЛР3/ЛР7 и выбег.
- Момент потерь: не более 10 % Mном (≈3 Нм), сухое трение + небольшая
  вентиляционная часть, чтобы выбег был близок к линейному (ЛР1 п.7,
  ЛР4 п.11, формула В.7). Сейчас 5,5 Нм при 2000 об/мин.
- ТП: внутреннее сопротивление Rп (ЛР2 п.4 просит его определить по
  наклону), Uвых = Kп·Uзад − I·Rп.
- ЭДС/ток ротора М3 для PV2/PA2: U2 = s·U2к, I2 по схеме замещения.
- Насыщение X0(I0) при ДТ АД (ЛР4 замечание) — желательно.

### 4. Компьютерный осциллограф (ЛР3, ЛР4 п.3–4, 9–10, ЛР5 п.7–9, ЛР6 п.5–6, ЛР7 целиком)

Окно «ПК» с аналогом PowerGraph: каналы ДТ1–ДТ3 (`sens.in`), ДН1–ДН2, ТГ,
ДМ, внутренние переменные преобразователей; старт/стоп записи, блоки,
курсор, шкалы, режим X‑Y, математика (умножение u·i, сложение, Smoothing,
интеграл), сохранение/загрузка настроек (наборы `LR7_delta_W2`, `LR7_W1`).
Для этого модель должна отдавать мгновенные значения: синтез синусоид по
действующему значению, фазе φ1 и частоте (f1 статора, f2 = s·f1 ротора)
достаточно для квазистатики; для ПЧ — ШИМ‑подобный сигнал напряжения не
обязателен, но фильтр Smoothing должен что‑то делать. Энергии ЛР7
(W1, ΔW1, ΔW2) можно считать интегрированием действующих значений.
Датчики ДТ/ДН должны измерять ток/напряжение реально проходящей через них
цепи (зависит от п. 1).

### 5. Параметры и рампы преобразователей (ЛР3 п.7, ЛР5 п.5–6, ЛР7 п.2–5)

- ТП: параметр 22.01 — время нарастания напряжения (5/2/1 с); режим
  «Настройка Руч/Фикс» сейчас только пишет в журнал.
- ПЧ: 28.72 — время частотного пуска (1/0,5 с), 97.13 — U при f = 0
  (IR‑компенсация, ломаная через (0,5fном; 0,5Uном)), 99.07 — Uном АД;
  задание f сейчас применяется скачком.
- ТПН: регулируемое время пуска (1 с в ЛР7), ограничение тока.
- Минимальный «пульт параметров» на лицевой панели преобразователя
  (несколько номеров с вводом значения) — достаточно.

### 6. Датчик момента при жёстком источнике скорости

В режимах ω ПЧ/ТП показывать момент в муфте как реакцию нагрузки
(−passive(ω) с учётом стороны), а не 0,0005·n. Иначе ФМ1/ФМ2 в режиме ω
(ДТ ДПТ/АДФР по методичке) не дают M.

### 7. Контакторы и цепь управления

- KM2/KM3 включаются автоматически по «Время 1/2» (0,5–10 с). Для
  статических характеристик (ЛР4 п.2, ЛР6 п.2) нужна возможность держать
  их разомкнутыми: положение «∞» потенциометра, либо катушки KM2/KM3 с
  клеммами, чтобы студент сам собирал цепь управления (как на рис. В.12).
- На стенде ДПТ KM1 подключает якорь к =240 В — контакты должны выдерживать
  постоянный ток; в модели ограничений нет — ок.

### 8. Мелочи, замеченные по пути

- PV2 стенда АД (кольца b–c) всегда 0.
- Ток статора АД в модели: I2 = 4·Iном·s/√(s²+sк²) при Iном = 20 А — не
  соответствует ни М3 (14,7 А), ни М4 (13,5 А); заменить схемой замещения.
- Ваттметр PW: U, I, P, cos φ по собственным клеммам.
- Хорошо бы: «Записать точку» — таблица снятых показаний (n, M, PV, PA, PW)
  с экспортом, вместо переписывания со стрелок; секундомер для выбега.
- Проверки схемы: предупреждение «резистор ни к чему не подключён» /
  «обмотка через резистор без источника» после п. 1.
