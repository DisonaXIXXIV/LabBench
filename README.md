# Визуальные модели лабораторных стендов «Электрический привод»

Интерактивные модели двух стендов кафедральной лаборатории (по методичке
`Benches Description.pdf`):

- **Стенд ДПТ** (шкафы А1–А6) — ТП, ПЧ, ДПТ НВ М1 + СДПМ М2;
- **Стенд АД** (шкафы Б1–Б6) — ПЧ, ТП, ТПН, АД с фазным
  ротором М3 + АД с к.з. ротором М4.

Чистый HTML/JS (ES-модули), без сборки.

Рядом с заголовком показывается версия — дата и время коммита из
`js/version.js`; файл пишет хук `.githooks/pre-commit`, который нужно
включить один раз после клонирования:

```bash
git config core.hooksPath .githooks
```

## Запуск

Нужен любой статический сервер (ES-модули не грузятся с `file://`):

```bash
python -m http.server 8765
```

и открыть <http://localhost:8765>.

## Компоновка

Экран повторяет вид стенда спереди (рис. В.1/В.6 методички и фото): ряд
шкафов слева направо, под ними столешница и цоколь с двухмашинным агрегатом
за сеткой ограждения.

| Стенд ДПТ | Стенд АД | Содержимое |
|---|---|---|
| А5, А6 | Б1, Б2 | автоматика стенда (декоративный шкаф, показывается при широком экране) |
| А4 | Б3 | ПК — на мониторе журнал диагностики, таблица снятых точек, осциллограф |
| А3 | Б4 | ТП (на стенде АД под ним ТПН) с органами управления |
| А2 | Б5 | кнопки «Ввод 1/2/3», приборы, стеклянная дверь монтажного отсека, «Пуск/Стоп/Время» |
| А1 | Б6 | автоматы, УЗО, аварийная кнопка; ПЧ с органами управления |

Ряд шкафов имеет естественную ширину около 1950 px; на более узком окне
страница масштабируется целиком (`App.setupFit`). Клик по стеклянной двери
шкафа А2/Б5 раскрывает наборное поле крупно под стендом (рядом — копия
журнала диагностики).

## Мобильная компоновка

На экранах уже 1000 px (`@media (max-width: 1000px)`, класс `body.mobile`,
`js/ui/mobile.js`) стенд показывается иначе: сверху — **миникарта**
(схематичный фасад стенда с подписями зон и живыми маркерами: питание
подано, дверь открыта, авария, вал вращается), под ней — **одна зона**
стенда в натуральную величину: ПК с журналом, шкаф ТП (ТП+ТПН), вводы и
приборы, наборное поле, автоматы и ПЧ, агрегат. Зона выбирается тапом по
карте или стрелками; карту можно свернуть до строки с названием зоны.
DOM тот же, что на десктопе, — CSS показывает один шкаф и переставляет его
содержимое в столбик, поэтому модель и все панели работают без изменений.

Тач: поле прокручивается одним пальцем и масштабируется двумя (до ~4000 px
по ширине), зоны попадания зажимов и проводов увеличены; тап по клеммнику
показывает подсказку, выбранный провод удаляется кнопкой «Удалить провод»;
цвета проводов — в заголовке поля; действия со схемой — в меню «⋯» шапки;
аварии и предупреждения журнала всплывают внизу экрана, а на зоне ПК
загорается маркер непрочитанных.

## Как пользоваться

1. Клик по **стеклянной двери** шкафа А2/Б5 — наборное поле раскрывается
   крупно; **открыть дверь** кнопкой в его заголовке.
2. Собрать схему: клик по свободному зажиму клеммника → клик по второму
   зажиму. Клеммники — пружинные push-in с тремя зажимами на общей шине:
   один занят внутренней проводкой стенда, два свободных расположены рядом
   на одной стороне (у верхней рейки — снизу, у средней — сверху). В один
   зажим входит один провод. Правая кнопка по проводу — удалить;
   клик + `Delete` — тоже. Цвет провода выбирается в шапке.
   `Ctrl`+колесо / кнопки «−/+» — масштаб поля.
   Компоновка отсека и цвета корпусов клеммников повторяют реальные шкафы
   А2 и Б5 (рис. В.11 методички): рейки с блоками клеммников и таблички
   со схемами, кружки которых стоят под/над соответствующими клеммниками.
   На стенде АД разрыв X2–X3 в цепи катушки KM1 нужно замкнуть проводом;
   блок KM4–KM8 на стенде ДПТ управляется из шкафа А6 и в модели не
   задействован.
3. **Проверить схему** — статическая проверка (КЗ между фазами, фаза–ноль,
   «+»/«−», сеть на выходе преобразователя, соединённые выходы разных
   преобразователей, неполные подключения и т.п.). Наведение на сообщение
   подсвечивает клеммы.
4. **Закрыть дверь**, включить УЗО → главный автомат → «Питание на приводы»
   и «Питание внутренних цепей», нажать «ВКЛ.» нужного ввода. При КЗ
   срабатывает расцепитель. Открытие двери под напряжением тоже.
5. Управлять преобразователями: тумблеры «Настройка», «Стабилизация»,
   «Полярность задания», потенциометр «Задание» (перетаскивание/колесо),
   кнопки «ВКЛ./ВЫКЛ.». ТП стенда ДПТ включается в две ступени: первое
   «ВКЛ.» подаёт возбуждение (В+/В−, ток по левому потенциометру), второе —
   якорную цепь; при токе возбуждения ниже 0,5 А ТП выдаёт аварию «ОШИБКА
   ТОКА ОВ». «ВЫКЛ.» — в обратном порядке; при аварии — сброс. Под полем — «Пуск/Стоп» цепи управления,
   потенциометры «Время 1/2» приставок выдержки времени KM2/KM3 (крайнее
   положение — «∞»: контактор автоматически не включается) и кнопки ручного
   включения KM2/KM3 — для статических характеристик с резисторами.
6. **Параметры преобразователей** — раскрывающийся пульт под лицевой
   панелью: ТП 22.01 (время нарастания напряжения), ПЧ 28.72 (время
   пуска), 97.13 (напряжение при f = 0, IR‑компенсация), 99.07 (Uном
   двигателя), ТПН — время пуска и ограничение тока. Действуют в положении
   «Руч.» тумблера «Настройка», в «Фикс.» — заводские значения.
7. **Монитор ПК** (шкаф А4/Б3): вкладки «Диагностика» (журнал), «Таблица»
   («Записать точку» — строка со всеми приборами, режимами преобразователей и
   контакторами; удаление, копирование, CSV, график n(X); секундомер и
   автоматическая фиксация выбега) и «Осциллограф» (аналог PowerGraph:
   запись блоками, каналы ДТ1–ДТ3, ДН1–ДН2, ТГ, ДМ и внутренние сигналы
   преобразователей, шкалы, курсор, X‑Y, математика — умножение, сложение,
   k·A + b, сглаживание, интеграл, наборы настроек `LR7_W1`, `LR7_delta_W1`,
   `LR7_delta_W2`, CSV). Кнопка «⤢ крупно» разворачивает вкладку под стендом.

Схема сохраняется в `localStorage` и экспортируется/импортируется в JSON.

## Электромеханическая модель

Работает `QuasiStaticModel` (`js/sim/model.js`): токи и напряжения —
действующие значения и фазоры, характеристики машин — по схемам замещения
с параметрами из методички, вал — уравнение движения. Модель считается
подшагами 5 мс (`runtime.tick` делит кадр), поэтому переходные процессы
пуска и выбега разрешаются по времени.

**Цепь.** Нетлист для модели строится без перемычек ваттметра и датчиков —
их пары клеммников становятся ветвями 0 Ом (`sim/circuit.js`), резисторы
стенда — ветвями с сопротивлением. От клеммников каждой обмотки модель
ищет путь к источнику (Дейкстра по сопротивлению): так учитываются
резисторы в якорной цепи и в фазах статора, нагрузка на выходе ТП, а токи,
прошедшие через ветви PW/ДТ, дают показания ваттметра и сигналы датчиков.
Потенциалы вдоль цепочки резисторов — с падением I·R, поэтому PV1/PV2
показывают напряжение на зажимах с учётом резисторов.

**Вал.** Если есть «жёсткий» источник скорости (ПЧ в режиме ω, ТП в
режиме ω, пока хватает напряжения и тока), вал следует за заданием. Иначе
интегрируется J·dω/dt = ΣM (неявный шаг Эйлера): моменты источников момента
(ПЧ в режиме M), моменты машин на характеристиках, тормозные моменты,
трение. Момент потерь — сухое трение ≈ 2,5 Нм + малая вентиляционная
составляющая, J агрегата 0,041 кг·м² (стенд ДПТ) и 0,12 (стенд АД). Датчик
момента показывает момент в муфте: момент нагрузочной машины (второй в
агрегате), а при жёстком источнике скорости на её стороне — реакцию всего,
что сидит на валу; положительный — нагрузочная машина крутит испытуемую.
Выбег от снятия питания до остановки фиксируется в журнал и на вкладке
«Таблица».

**ДПТ** (М1: 1750 об/мин, 28 А, 240 В, Rя 1,03 Ом, Rв 167 Ом, kΦ =
(Uн − IнRя)/ωн · Iв/Iв.ном). Якорь: I = (U − kΦω)/(Rя + Rд + Rп), M = kΦ·I.
ТП: режим U — задание с рампой по параметру 22.01, ЭДС холостого хода и
внутреннее сопротивление Rп = 0,5 Ом (Uвых = Uзад − I·Rп), ограничение тока
регулятором `ilim`; режим I — ТП держит ток, поднимая напряжение до
`umax`; режим ω — жёсткий источник скорости с переходом в ограничение тока
или напряжения. Возбудитель: U_в = I_в·R_в по заданию, авария «ОШИБКА
ТОКА ОВ» при I_в < `fieldMin`. Динамическое торможение: якорь без
источника, замкнутый накоротко или на резистор при поданном возбуждении —
I = −kΦω/(Rя + Rдт). Без возбуждения — разнос.

**АД** (М3 MTF112-6, М4 M3AA132MC) — Т-образная схема замещения
(`bench.motors[].im`: r1, x1, r2, x2, x0; kpr — коэффициент приведения
ротора, kd — вытеснение тока в к.з. роторе): I1, I2', M, cos φ1, P1 по
формулам (4.4)–(4.7) методички при фазном напряжении, частоте и скорости;
генераторный режим и противовключение — по знаку скольжения. Добавочное
сопротивление ротора М3 читается по нетлисту (кольца, резисторы 4,2/1,2 Ом
через контакты KM) и приводится через kpr²; PA2 показывает неприведённый
ток ротора, PV2 — напряжение на кольцах (s·U2к при разомкнутом роторе).
М4 — 380 Δ / 660 Y: номинальная схема — треугольник (фаза на 380 В),
звезда на сети 380 В — пониженное напряжение (Mк в три раза меньше, ток
холостого хода в три раза меньше); амперметр показывает линейный ток.
От ПЧ в режиме f — U(f) по параметрам 97.13/99.07 с рампой 28.72; в
режимах M/ω — векторное управление (ток по требуемому моменту). Опрокидывание
при моменте нагрузки больше критического — `stall`.

**Динамическое торможение АД**: постоянный ток от ТП в двух (трёх) фазах,
I = Uтп/(2·r1 + Rп), эквивалентный переменный ток Iэ = I·√(2/3) (или I/√2),
момент по (4.13)–(4.15): I2' = Iэ·x0/√((r2'/ν)² + (x0 + x2')²),
M = 3·I2'²·r2'/(ν·ω0), с насыщением x0 при Iэ выше тока холостого хода.

**ТПН**: рампа напряжения за «время пуска», при токе выше ограничения рампа
ждёт; после разгона — байпас K4 (выход ТПН становится просто сетью).

**Рекуперация ПЧ**: если у преобразователя описаны выводы тормозного ключа
(`brake: ['fc.br.Br+', 'fc.br.Br−']`, стенд АД) и машина от ПЧ работает
генератором, то без резистора R1 между Br+ и Br− через 0,5 с наступает
авария «ПЕРЕНАПРЯЖЕНИЕ ЗПТ»; с резистором ток через него показывается на
осциллографе. Ток на входе ПЧ/ТП/ТПН считается по мощности и проходит через
измерители между сетью и входом преобразователя (форма — см. ниже).

**Сигналы осциллографа.** Модель отдаёт для каждого сигнала постоянную
составляющую и набор гармоник {rms, f, фаза, источник частоты}; мгновенные
значения синтезирует `model.sample(t)` по накопленным фазам источников (сеть
50 Гц, выход ПЧ, ток ротора f2 = s·f1, пульсации ТП 300 Гц, ШИМ‑остаток).

Ток на входе ПЧ и ТП несинусоидальный (`js/sim/waves.js`), его форма —
таблица на период сети, нормированная по первой гармонике, так что в сигнале
она участвует как обычная составляющая {rms, фаза} с полем `wave`:

- **ПЧ** — диодный мост с ёмкостью звена: форма считается численным
  интегрированием схемы «сеть (L на фазу) — мост — дроссель звена Ldc —
  ёмкость C — нагрузка постоянной мощности» до установившегося режима
  (параметры `input: {L, C, Ldc}` в описании ПЧ, типовые значения). По два
  импульса за полупериод у вершин линейных напряжений; при малой нагрузке —
  узкие и острые, с ростом мощности шире. Под напряжением ПЧ потребляет
  40 Вт и без нагрузки. Формы кэшируются по ступеням мощности через 4 %.
- **ТП** — шестипульсный мост от сети 380 В (Ud0 = 513 В): блоки по 120°,
  сдвинутые на угол управления α (Ud = Ud0·cos α − 3·X·Id/π) и с наклонными
  фронтами на угле коммутации μ (`xc` — индуктивное сопротивление сети на
  фазу). Возбудитель — небольшая синусоидальная добавка.

Фаза тока отсчитывается от фазы сети, к которой подключён клеммник A
преобразователя. Ваттметр PW показывает полное действующее значение тока
(с гармониками), поэтому его коэффициент мощности на входе ПЧ — 0,55–0,7.

Полноценная модель приводов (уравнения машин, преобразователей, механики)
реализует тот же интерфейс:

```js
class ElectroMechModel extends DriveModel {
  reset() {}
  step(ctx) {
    // ctx.dt, ctx.nl (нетлист без перемычек), ctx.probes, ctx.bench, ctx.converters, ctx.contactors
    return { potentials, meters, shaft: { speed, torque }, motors, currents, conv, signals, events };
  }
  sample(t) { /* мгновенные значения сигналов */ }
}
```

и регистрируется в `js/sim/index.js` (`MODELS`, `DEFAULT_MODEL`).
