# Визуальные модели лабораторных стендов «Электрический привод»

Интерактивные модели двух стендов кафедральной лаборатории (по методичке
`Benches Description.pdf`):

- **Стенд ДПТ** (шкафы А1–А6) — ТП, ПЧ, ДПТ НВ М1 + СДПМ М2;
- **Стенд АД** (шкафы Б1–Б6) — ПЧ, ТП, ТПН, АД с фазным
  ротором М3 + АД с к.з. ротором М4.

Чистый HTML/JS (ES-модули), без сборки.

## Запуск

Нужен любой статический сервер (ES-модули не грузятся с `file://`):

```bash
python -m http.server 8765
```

и открыть <http://localhost:8765>.

## Компоновка

Экран повторяет вид стенда спереди (рис. В.1/В.6 методички и фото): ряд
шкафов слева направо, под ними столешница и цоколь с двухмашинным агрегатом
за сеткой ограждения.

| Стенд ДПТ | Стенд АД | Содержимое |
|---|---|---|
| А5, А6 | Б1, Б2 | автоматика стенда (декоративный шкаф, показывается при широком экране) |
| А4 | Б3 | ПК — на мониторе журнал диагностики |
| А3 | Б4 | ТП (на стенде АД под ним ТПН) с органами управления |
| А2 | Б5 | кнопки «Ввод 1/2/3», приборы, стеклянная дверь монтажного отсека, «Пуск/Стоп/Время» |
| А1 | Б6 | автоматы, УЗО, аварийная кнопка; ПЧ с органами управления |

Ряд шкафов имеет естественную ширину около 1950 px; на более узком окне
страница масштабируется целиком (`App.setupFit`). Клик по стеклянной двери
шкафа А2/Б5 раскрывает наборное поле крупно под стендом (рядом — копия
журнала диагностики).

## Как пользоваться

1. Клик по **стеклянной двери** шкафа А2/Б5 — наборное поле раскрывается
   крупно; **открыть дверь** кнопкой в его заголовке.
2. Собрать схему: клик по свободному зажиму клеммника → клик по второму
   зажиму. Клеммники — пружинные push-in с тремя зажимами на общей шине:
   один занят внутренней проводкой стенда, два свободных расположены рядом
   на одной стороне (у верхней рейки — снизу, у средней — сверху). В один
   зажим входит один провод. Правая кнопка по проводу — удалить;
   клик + `Delete` — тоже. Цвет провода выбирается в шапке.
   `Ctrl`+колесо / кнопки «−/+» — масштаб поля.
   Компоновка отсека и цвета корпусов клеммников повторяют реальные шкафы
   А2 и Б5 (рис. В.11 методички): рейки с блоками клеммников и таблички
   со схемами, кружки которых стоят под/над соответствующими клеммниками.
   На стенде АД разрыв X2–X3 в цепи катушки KM1 нужно замкнуть проводом;
   блок KM4–KM8 на стенде ДПТ управляется из шкафа А6 и в модели не
   задействован.
3. **Проверить схему** — статическая проверка (КЗ между фазами, фаза–ноль,
   «+»/«−», сеть на выходе преобразователя, соединённые выходы разных
   преобразователей, неполные подключения и т.п.). Наведение на сообщение
   подсвечивает клеммы.
4. **Закрыть дверь**, включить УЗО → главный автомат → «Питание на приводы»
   и «Питание внутренних цепей», нажать «ВКЛ.» нужного ввода. При КЗ
   срабатывает расцепитель. Открытие двери под напряжением тоже.
5. Управлять преобразователями: тумблеры «Настройка», «Стабилизация»,
   «Полярность задания», потенциометр «Задание» (перетаскивание/колесо),
   кнопки «ВКЛ./ВЫКЛ.». ТП стенда ДПТ включается в две ступени: первое
   «ВКЛ.» подаёт возбуждение (В+/В−, ток по левому потенциометру), второе —
   якорную цепь; при токе возбуждения ниже 0,5 А ТП выдаёт аварию «ОШИБКА
   ТОКА ОВ». «ВЫКЛ.» — в обратном порядке; при аварии — сброс. Под полем — «Пуск/Стоп» цепи управления и
   потенциометры «Время 1/2» приставок выдержки времени KM2/KM3.

Схема сохраняется в `localStorage` и экспортируется/импортируется в JSON.

js/core/runtime.js      — логика стенда: автоматы, вводы, дверь, цепь
                          управления KM1–KM3, преобразователи, защиты

## Электромеханическая модель

Сейчас работает `QuasiStaticModel` (`js/sim/model.js`): потенциалы сетей по
источникам, показания приборов по разности потенциалов, токи — по упрощённым
формулам.

**Вал.** Если есть «жёсткий» источник скорости (ПЧ в режиме ω, ТП в режимах
ω/U/I на ДПТ), вал следует за заданием. Иначе интегрируется уравнение
движения J·dω/dt = ΣM (неявный шаг Эйлера): моменты источников момента (ПЧ/ТП
в режиме M), моменты АД по их характеристикам, тормозные моменты, трение.
Поэтому ПЧ в режиме момента без нагрузки разгоняет агрегат до срабатывания
защиты по скорости, а под нагрузкой скорость устанавливается на пересечении
характеристик.

**АД на характеристике** (питание от сети, ТПН или ПЧ в режиме f) — формула
Клосса M = 2·M_к·s·s_к/(s² + s_к²), где s_к = (r2 + R_доб)/x_к: добавочное
сопротивление ротора фазного АД считается по нетлисту (кольца накоротко,
резисторы 4,2/1,2 Ом, их последовательное включение через контакты KM) и
делает характеристику мягче при том же M_к. Напряжение ТПН снижает M_к ∝ U²;
ПЧ в режиме f задаёт ω₀ по частоте (выше 50 Гц — ослабление поля). Если момент
нагрузки больше критического, двигатель опрокидывается (`stall`), ток статора
растёт до пускового. Токи: I₂ = I₂к·s/√(s² + s_к²), I₁ = √(I₀² + I₂²).
Датчик момента `M` показывает момент в муфте: отрицательный — испытуемая
машина (первая в агрегате) крутит нагрузочную, положительный — наоборот; так
в режиме ω ПЧ можно снять МХ АД по точкам.

**Динамическое торможение АД**: если на статор подан только выход работающего
ТП («+» и «−» на двух фазах, третья свободна, или «+» на одной и «−» на двух),
двигатель переходит в состояние `brake`. Ток статора I = U_тп / (2·r1),
тормозная характеристика M(ω) = 2·M_к·(ω/ω_к)/(1+(ω/ω_к)²), где M_к ∝ I², а
ω_к = ω₀·(r2 + R_доб)/x_m.

**Рекуперация ПЧ**: если у преобразователя описаны выводы тормозного ключа
(`brake: ['fc.br.Br+', 'fc.br.Br−']`, стенд АД) и машина от ПЧ работает
генератором (ПЧ держит скорость ниже синхронной АД от сети, нагружает вал в
режиме M и т.п.), то без резистора R1 между Br+ и Br− через 0,5 с наступает
авария «ПЕРЕНАПРЯЖЕНИЕ ЗПТ»; сброс аварии — кнопкой «ВЫКЛ.» преобразователя.

**Возбудитель ТП** (стенд ДПТ): выходы `fieldOut` (В+/В−) включаются
первой ступенью «ВКЛ.»; напряжение на них U_в = I_в·R_в по заданию тока ОВ,
модель сообщает ток возбудителя `conv.tp.If`. Якорная цепь включается
второй ступенью только при I_в ≥ `fieldMin`, иначе (и при падении тока во
время работы) — авария «ОШИБКА ТОКА ОВ».

**Токовая защита ТП**: модель считает ток выхода ТП (якорь ДПТ или постоянный
ток в статоре АД при динамическом торможении, I = U_тп/(2·r1)); при
превышении `imax` преобразователя — авария «ПРЕВЫШЕНИЕ ТОКА». Текущий ток
показан на дисплее ТП.

Параметры машин — `bench.motors[].im` (`r1`, `r2`, `xm`, `xk`, `mcr`, `mk`).
Полноценная модель приводов (уравнения машин, преобразователей, механики)
реализует тот же интерфейс:

```js
class ElectroMechModel extends DriveModel {
  reset() {}
  step(ctx) {
    // ctx.dt, ctx.nl (нетлист), ctx.bench, ctx.converters, ctx.contactors
    return { potentials, meters, shaft: { speed, torque }, motors, currents, events };
  }
}
```

и регистрируется в `js/sim/index.js` (`MODELS`, `DEFAULT_MODEL`). Нагрузки
(обмотки, резисторы) в нетлисте сети не объединяют — их параметры описаны в
`bench.motors` / `bench.resistors`, а топология подключения читается через
`ctx.nl.netOf(nodeId)`.
